# Security Policy

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Until a dedicated security contact is configured for this repository, open a GitHub Security Advisory if the repository supports it.

When reporting, include:

- affected version/commit
- affected file/module
- reproduction steps
- impact
- suggested remediation if known

Do not include real credentials, personal data, or secrets.

## Scope

Security reports are welcome for:

- Cybora source code
- dependency handling
- unsafe network behavior
- report generation
- authorization/safety boundary failures
- supply-chain issues

## Responsible use

Cybora is designed for authorized defensive assessment. Findings about third-party infrastructure should only be produced when testing was explicitly authorized.
