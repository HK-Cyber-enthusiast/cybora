## LinkedIn launch post

🚀 Introducing **Cybora** — a free, modular cybersecurity assessment project.

I’m building Cybora around one idea: security checks should be easier to run and easier to understand. The foundation brings several defensive checks behind one CLI, including website security baselines, repository secret-pattern checks, dependency hygiene, local system observations, and loopback-only service checks.

Instead of leaving results scattered across tools, Cybora normalizes findings, applies a transparent risk score, and can export JSON reports for future automation.

🧪 This is an early foundation release—not a claim to replace professional enterprise platforms. The next stages are security-intelligence enrichment, richer assessment modules, and cross-finding correlation.

Built with Python, with a focus on open development, clear limitations, and authorized defensive use. Feedback, issues, and contributions are welcome!
