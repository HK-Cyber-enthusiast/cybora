# Release Readiness Checklist

## Before public push
- [ ] Confirm `Cybora` name and package namespace are suitable; no uniqueness guarantee is implied.
- [ ] Review all source files and dependencies.
- [ ] Run in a clean Python 3.14.4 virtual environment.
- [ ] `python -m pip check` passes.
- [ ] `pytest -q` passes.
- [ ] `ruff check .` passes.
- [ ] `ruff format --check .` passes.
- [ ] `cybora --help`, `cybora --version`, and `cybora demo` work.
- [ ] Test each module on a safe, owned/local target.
- [ ] Verify JSON output and error handling.
- [ ] Remove secrets, `.env`, local reports, caches, `.venv`, and generated bytecode.
- [ ] README's implemented features match actual code.
- [ ] Add real repo URL to `POSTING_KIT.md` before sharing.
- [ ] Review the license and contributor identity/copyright line.

## First push
```bash
git init
git branch -M main
git add .
git status --short
git diff --cached --check
git commit -m "Initial Cybora foundation release"
git remote add origin https://github.com/YOUR_USERNAME/cybora.git
git push -u origin main
```

## After push
- [ ] Confirm GitHub Actions completes successfully.
- [ ] Confirm README, license, and topics display properly.
- [ ] Add repository description and social preview image.
- [ ] Create a GitHub release only after a clean install/test on Python 3.14.4.
